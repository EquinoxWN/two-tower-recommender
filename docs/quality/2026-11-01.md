# Quality check 2026-11-01

The ten quality rules checked against the code, with evidence. Python 3.14 venv, CPU torch,
Windows 11. The only external call is the MovieLens download; everything else is in-process
training, indexing and evaluation.

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Every call can fail | fixed | `download` uses `urlopen(..., timeout=60)`, https only, a size cap and a SHA-256 check; it does not retry (one archive, a clear error is enough). Found: an error in the middle of the transfer left the `.part` file behind; now removed on any failure (`test_a_download_that_fails_midway_leaves_no_partial_file`). Found: a malformed archive raised a bare `IndexError`/`ValueError`/`KeyError` with a traceback; now a `DataError`, which the CLI turns into exit 2. ruff with `S`, `B` and `BLE`-relevant rules is clean; no `except: pass`. |
| 2 | Writes safe to retry | pass | The download writes `.part` and renames it into place only after the checksum matches; a second call with a good file returns at once (`sha256(dest) == expected`). No other writes. |
| 3 | No race conditions | N/A | Single process, no threads of its own (FAISS and torch threads work on their own data). |
| 4 | Don't trust the clock | pass | Latency uses `time.perf_counter` (`retrieval.latency_ms`, `cli.py`). The time split orders ratings by the dataset's own timestamps, which is the data's meaning, not a clock reading. |
| 5 | Read before changing | pass | APIs exist in the installed versions (mypy `--strict` clean). No environment variables are read; the data path is a documented flag. |
| 6 | Never break compatibility | pass | No persisted formats besides the downloaded archive; the CLI flags are unchanged (only invalid `--epochs` values are now refused). |
| 7 | One source of truth | pass | The archive is verified against the pinned SHA-256 (derived from GroupLens' published MD5, as the code comment says) and re-downloaded when it does not match. Python version: `requires-python >=3.11`, README 3.11+, CI 3.12. |
| 8 | Small changes, no secrets, validate input | fixed | No secrets. Found: `--epochs 0` or negative ran an empty training; now refused (exit 2). Found: archive contents were not validated (see rule 1). No new dependency. |
| 9 | Tests that can fail | fixed | No skips or tautologies. Mutation table below: 11 of 14 killed before, 14 of 14 after. Mutation runs deselected the three slow end-to-end tests (planted-preference training, synthetic CLI run, training reproducibility), so the scores are a lower bound. |
| 10 | Re-verify | pass | `ruff check`/`format --check`, `mypy --strict`: clean; `pytest`: 32 passed; `pip-audit`: no known vulnerabilities (with an upgraded pip). The CI result is recorded in the commit's workflow run. |
